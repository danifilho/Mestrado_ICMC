# Snapshot documental do Piloto 7 — 19/11/2026

Esta pasta preserva código, tabelas, quatro figuras locais, quatro figuras principais de Wright, os quatro suplementos, 36 páginas rasterizadas do suplemento de figuras e outputs simulados por repetição. Não é uma nova execução do HPCC.

Leia a Wiki: https://github.com/danifilho/Mestrado_ICMC/wiki/Piloto-7-Wright-Documentacao-integral

Os resultados históricos foram preservados. `auditoria/sensibilidade_empates.csv` é uma reanálise posterior, com script próprio. `extensao_AD` é snapshot preparatório, não resultado final certificado. Os dados individuais treino/teste e objetos completos de modelos não estavam no conjunto local consultado; seus geradores e sementes estão documentados. Outputs v0 inválidos não são usados nas figuras finais; o inventário preserva identificação dos originais.

Para os dados por repetição, descompacte resultados/*_brutos.tar.gz dentro de resultados/brutos/. Preserve os nomes internos. Os comandos de análise e as versões estão no anexo de reprodução da Wiki. Não execute novos jobs sem orçamento autorizado.
